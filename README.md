# Capital Growth System (CGS) — Полная документация

## 1. Философия и цели системы

### Ключевые принципы
- **Рост количества BTC**, а не доход в долларах — главная метрика успеха
- **Реинвестирование прибыли** обратно в Growth Zone
- **"Вечный портфель"** — базовые активы (BTC) никогда не продаются
- **DCA-инвестиции** — регулярные пополнения как топливо стратегии

### Структура портфеля: 3 зоны

| Зона | Назначение | Типичная доля |
|------|------------|---------------|
| **Growth Zone** | BTC в залоге, генерация займа | 40–60% |
| **Stability Zone** | Стейблкоины для докупок при просадках | 40–60% |
| **Yield Zone** | Заёмные средства в работе (DeFi) | = размер займа |

## 2. Growth Zone — Механика залога

### Параметры
| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| Initial LTV | 50% | Начальный уровень закредитованности |
| Liquidation Threshold | 85% | Порог ликвидации |
| Протоколы | Fluid, Morpho, Aave | Lending-платформы для залога |

### Формулы

**Health Factor (HF):**
$$HF = \frac{Collateral \times LiqThreshold}{Debt}$$

**LTV:**
$$LTV = \frac{Debt}{Collateral} \times 100\%$$

### Интерпретация Health Factor
| HF | Статус | Действие |
|----|--------|----------|
| > 1.5 | ✅ Безопасно | Нет действий |
| 1.2–1.5 | ⚠️ Внимание | Мониторинг |
| < 1.2 | 🔴 Опасно | Срочные меры |
| < 1.0 | ❌ Критично | Риск ликвидации |

## 3. Yield Zone — Стратегии заёмных средств

### Распределение (по умолчанию)
| Компонент | Доля | Назначение |
|-----------|------|------------|
| **GM Pool** | 40% | AMM-токены BTC/USDC |
| **CLMM** | 30% | Concentrated Liquidity позиции |
| **Stablecoins Reserve** | 30% | Резерв для 2-й CLMM позиции |

**Важно:** Сумма GM + CLMM + Reserve = 100% от займа

## 4. Расчёт GM токенов (AMM)

### Модель: Uniswap V2 / Constant Product

**Инвариант пула:**
$$k = x \cdot y = const$$

**Стоимость позиции:**
$$V = 2\sqrt{k \cdot P}$$

### Формула изменения стоимости GM

$$\frac{V_{new}}{V_{old}} = \sqrt{\frac{P_{new}}{P_{old}}}$$

или

$$GM_{change} = \sqrt{1 + \Delta_{BTC}} - 1$$

### Таблица изменений GM при падении BTC

| Падение BTC | Множитель r | Изменение GM |
|-------------|-------------|--------------|
| -7% | 0.93 | **-3.6%** |
| -15% | 0.85 | **-8.2%** |
| -30% | 0.70 | **-16.3%** |
| -50% | 0.50 | **-29.3%** |
| -70% | 0.30 | **-45.2%** |

### Механика продажи GM
При продаже GM токенов:
- **50% → BTC** (отправляется в залог)
- **50% → USDC** (+ Stability Zone → покупка новых GM)

## 5. Расчёт CLMM позиций (Concentrated Liquidity)

### Модель: Uniswap V3

**Параметры ренжа:**
- Нижняя граница: **-15%** от точки входа
- Верхняя граница: **+5%** от точки входа

### Формулы

**Liquidity (L):**
$$L = \frac{V_0}{2\sqrt{P_0} - \frac{P_0}{\sqrt{P_b}} - \sqrt{P_a}}$$

где:
- $V_0$ — начальная стоимость позиции
- $P_0$ — цена входа
- $P_a$ — нижняя граница ренжа
- $P_b$ — верхняя граница ренжа

**Количество активов внутри ренжа ($P_a < P < P_b$):**
$$x_{BTC} = L \times \left(\frac{1}{\sqrt{P}} - \frac{1}{\sqrt{P_b}}\right)$$

$$y_{USDC} = L \times \left(\sqrt{P} - \sqrt{P_a}\right)$$

**Стоимость позиции:**
$$V = x \times P + y$$

### Средняя цена покупки BTC (при выходе за ренж)
$$P_{avg} = \sqrt{P_{entry} \times P_{exit}}$$

**BTC получено:**
$$BTC = \frac{USDC}{\sqrt{P_{entry} \times P_{exit}}}$$

## 6. Действия при ПАДЕНИИ рынка

### Stability Zone

| Просадка BTC | Действие |
|--------------|----------|
| -15% | Ничего не делать |
| **-30%** | 30% USDC → покупка GM |
| -40% | *Мониторинг* |
| **-50%** | 40% USDC → покупка GM |
| -60% | *Мониторинг* |
| **-70%** | 30% USDC → покупка GM |

### GM Pool

| Просадка BTC | Действие |
|--------------|----------|
| **-7%** | Продать 30% GM → BTC в залог, USDC → купить GM снова |
| **-15%** | Продать ВСЕ GM → BTC в залог, USDC → купить GM снова |
| **-30%** | Продать ВСЕ GM → BTC в залог, USDC → купить GM снова |
| -40% | *Мониторинг* |
| **-50%** | Продать ВСЕ GM → BTC в залог, USDC → купить GM снова |
| -60% | *Мониторинг* |
| **-70%** | Продать ВСЕ GM → BTC в залог, USDC → купить GM снова |

### CLMM

| Просадка BTC | Действие |
|--------------|----------|
| **0%** | Открыть CLMM #1 на 30% займа (ренж -15% / +5%) |
| **-15%** | CLMM #1 полностью в BTC → залог. Открыть CLMM #2 из Reserve |
| **-30%** | CLMM #2 полностью в BTC → залог. **STOP** (больше не открываем) |
| -40% | *Мониторинг* |
| -50% | STOP |
| -60% | *Мониторинг* |
| -70% | STOP |

**Особый случай:** Если CLMM = 0%, при -15% Reserve идёт на покупку GM (вместо открытия CLMM#2)

**Мониторинг (-40%, -60%):** Никаких активных действий. Стоимость позиций пересчитывается пассивно для отслеживания состояния портфеля.

### Stablecoins Reserve

| Просадка BTC | Действие |
|--------------|----------|
| **-15%** | Весь Reserve → открытие CLMM #2 (или → GM если CLMM = 0%) |

## 7. Ключевые метрики мониторинга

### S/G Ratio (Stability/Growth)

Отображается как дробь **X/Y** где X + Y = 100 (аналогично слайдеру настроек).

$$S\% = \frac{Stability}{Stability + Collateral} \times 100$$

| Значение | Интерпретация |
|----------|---------------|
| 0/100 | Все стейблы израсходованы (100% в залоге) |
| 40/60 | Стандартное распределение |
| 50/50 | Баланс 50/50 |
| 60/40 | Консервативный портфель (больше стейблов) |

**Примечание:** Reserve из Yield Zone не учитывается в S/G — только Stability Zone и Collateral.

### Y/L Ratio (Yield/Loan)
$$Y/L = \frac{GM + CLMM + Reserve}{Debt}$$

| Значение | Интерпретация |
|----------|---------------|
| > 1 | Yield Zone покрывает долг (хорошо) |
| = 1 | Нейтрально |
| < 1 | Долг больше Yield Zone (внимание!) |
| 0 | Yield Zone израсходована |

## 8. Потоки капитала

### DeFi доходы → Growth Zone

| Источник | Направление |
|----------|-------------|
| Комиссии от CLMM | → Growth Zone (залог) |
| APY за Stability стейблкоины | → Growth Zone (залог) |
| APY за Reserve стейблкоины | → Growth Zone (залог) |

**Growth Zone пополняется только из внутренних источников системы, не из DCA.**

### DCA → Stability или Yield Zone

Логика направления DCA основана на сравнении отклонений:

$$\text{Отклонение S/G} = \frac{|\text{текущий} - \text{целевой}|}{\text{целевой}}$$

$$\text{Отклонение Y/L} = \frac{|\text{текущий} - 1.0|}{1.0}$$

| Условие | DCA направить в |
|---------|-----------------|
| HF < 1.5 | **Stability Zone** (безопасность приоритет) |
| HF ≥ 1.5, отклонение Y/L > отклонение S/G | **Yield Zone** |
| HF ≥ 1.5, отклонение S/G > отклонение Y/L | **Stability Zone** |

**Принцип:** DCA идёт в зону с большим отклонением от цели для восстановления баланса.

## 10. Важные замечания

### Ограничения симуляции
⚡ Симуляции показывают **только защитную механику** при падении рынка без учёта:
- Доходности DeFi-позиций (APY)
- Регулярных DCA-инвестиций
- Комиссий и slippage

### Риски
- При падении свыше **-55–60%** HF приближается к критическому уровню
- Ликвидация возможна при HF < 1.0 (LTV > 85%)
- Impermanent Loss в GM и CLMM позициях

### Протоколы
- **Залог:** Fluid, Morpho, Aave
- **GM Pool:** GMX Protocol
- **CLMM:** Uniswap V3, Raydium, Orca

### Capital Growth

Версии Capital Growth симулятора:
- **Базовая** — HF до/после, колонки GM/CLMM/Reserve/Stability
- **Расширенная** — + S/G и Y/L Ratio до/после действий с отклонениями

### Capital Growth Dynamic

Экспериментальная модификация Capital Growth с триггерами на основе Health Factor:

**Отличия от базовой версии:**
- Триггеры срабатывают при HF < 1.45 (вместо фиксированных уровней % падения BTC)
- Yield Zone включает CLMM позиции (40% GM, 30% CLMM, 30% Reserve)
- CLMM ренж: -15% / +5% от точки входа

**Последовательность триггеров:**
1. HF < 1.45 + CLMM вышел из ренжа → CLMM#1 → BTC в залог, Reserve → CLMM#2
2. HF < 1.45 + CLMM#2 вышел → CLMM#2 → BTC в залог, CLMM STOP
3. HF < 1.45, нет CLMM → Продажа GM с подливом из Stability Zone

**Преимущества HF-триггеров:**
- Учитывают доходы с DeFi (реинвестирование в залог)
- Объективная метрика здоровья позиции
- Регулярные DCA-пополнения могут отодвигать триггеры

### Capital Growth: Full Cycle 2021-2024

Симуляция **полного рыночного цикла**: падение (реальные данные) + восстановление (расчетные данные).

**Параметры полного цикла:**
- Полный период: **866 дней** (10 ноября 2021 — 14 марта 2024)
- Начальная цена (ATH 2021): **$68,982**
- Конечная цена (ATH 2024): **$73,805**
- **Итоговый результат: +7%** (новый ATH)

**Фаза 1: Падение (Bear Market) — 376 дней**
- Период: **10 ноября 2021 — 21 ноября 2022**
- Цены: $68,982 → $15,768
- Падение: **-77.2%**
- Данные: **Реальные исторические цены**
- Ключевые события: Terra Luna crash (май '22), FTX collapse (ноябрь '22)

**Фаза 2: Восстановление (Recovery) — 490 дней**
- Период: **21 ноября 2022 — 14 марта 2024**
- Цены: $15,768 → $73,805
- Рост: **+368%** от минимума
- Данные: **Расчетные** (ежедневный рост ~0.317%)
- Новый ATH превышает предыдущий на 7%

**Ключевые даты цикла:**
- **10 ноября 2021** — All-Time High ($68,982)
- **Май 2022** — Крах Terra Luna
- **11 ноября 2022** — Крах FTX (катализатор минимума)
- **21 ноября 2022** — Достижение минимума ($15,768)
- **14 марта 2024** — Новый ATH ($73,805)

**Формулы:**
```
Phase 1 (Bear): Daily Multiplier = (15768/68982)^(1/376) = 0.9954967
               Daily Drop: -0.45%

Phase 2 (Recovery): Daily Multiplier = (73805/15768)^(1/490) = 1.003174
                   Daily Growth: +0.317%
```

**Особенности полного цикла:**
- **866 дней** непрерывной симуляции (2.4 года)
- Триггеры работают **только в фазе падения** (дни 1-376)
- Маркер перехода к фазе восстановления (день 377)
- Регулярные DCA-инвестиции (по умолчанию $1000 каждые 30 дней)
- Автоматическое распределение DCA по зонам портфеля
- Балансировка S/G и Y/L Ratio через DCA
- Графики фильтруются (каждый 20-й день + триггеры + маркер фазы)

**DCA Parameters:**
| Параметр | Значение по умолчанию | Описание |
|----------|----------------------|----------|
| DCA Interval | 30 дней | Периодичность DCA-инвестиций |
| DCA Amount | $1000 | Размер DCA пополнения |
| Target Y/L Ratio | 1.0 | Целевое соотношение Yield/Loan |

**Логика распределения DCA:**
1. **S/G < target**: DCA → Stability Zone (перекос в Growth)
2. **S/G >= target, Y/L < 1.0**: DCA → GM Pool (Yield Zone мала)
3. **S/G >= target, Y/L >= 1.0**: DCA → BTC в залог (всё в норме)

**Преимущества симуляции полного цикла:**
- **Полная картина** — показывает не только падение, но и восстановление
- **Реалистичность** — использует точные исторические цены для фазы падения
- **Долгосрочная перспектива** — 2.4 года от ATH до нового ATH
- **Проверка стратегии** — как Capital Growth работает в полном рыночном цикле
- **Сравнение результатов** — BTC восстановился на +7%, а ваш портфель?
- **Временные рамки** — восстановление заняло на 30% больше времени чем падение (490 vs 376 дней)

### Hybrid Model

Особенности Hybrid модели:
- Гибкий слайдер Growth/Stability (½ Stability → Yield)
- CLMM ренж: **+10% / -25%** (шире чем в Capital Growth)
- Debt направляется в CLMM для увеличения дохода
- Показывает ожидаемый ежемесячный доход (CLMM APR + Stability APR)
- Автоматическая ребалансировка при -25%, -45%, -60%

## 13. Hybrid Model — Детали

### Распределение

При выборе Growth/Stability через слайдер:
- **Growth Zone** — выбранный % (BTC в залоге)
- **Yield Zone** — ½ от Stability + Debt → CLMM
- **Stability Zone** — ½ от оставшегося (стейблкоины)

Пример при слайдере 50/50:
- Growth: 50%
- Yield: 25% + Debt (займ)
- Stability: 25%

### Параметры по умолчанию

| Параметр | Значение |
|----------|----------|
| Initial LTV | 30% |
| Liquidation Threshold | 85% |
| CLMM APR | 25% |
| Stability APR | 10% |
| CLMM ренж | +10% / -25% |

### Действия при падении

| Уровень | Действие |
|---------|----------|
| **-25%** | CLMM#1 → BTC → залог. Займ до 30% LTV. Stability + займ → CLMM#2 |
| **-45%** | CLMM#2 → BTC → залог. Займ до 60% LTV. Займ → CLMM#3 |
| **-60%** | CLMM#3 → BTC → залог. STOP |
